# Security policy

This repository is the PARADA project site: a static website with no server, database, accounts or secrets. The one third-party service is Vercel Web Analytics (cookieless, same-origin).

## Reporting a vulnerability

Please report it privately through GitHub: **[Report a vulnerability](https://github.com/E1yWrites/parada-landing/security/advisories/new)**. Do not open a public issue for it.

Useful reports include a way to reproduce the problem and the page or file involved. This is a student capstone project maintained by a small team, so please allow a few days for a reply.

## Scope

In scope: this site's code and its deployment headers (`vercel.json`). The PARADA application itself (API, mobile and admin apps) lives in [E1yWrites/parada](https://github.com/E1yWrites/parada); report problems there instead.
